# 💛 دعوت‌نامه دیجیتال عروسی ایوب و غزل

یک تجربه دعوت‌نامه دیجیتال لوکس، عاشقانه و تعاملی — با کارت دعوت گل‌آرایی‌شده،
ترنزیشن سینمایی باز شدن پرده، تالار جشن با چراغونی و موسیقی شاد.

---

## ▶️ روش اجرا

پروژه با **Next.js 16 + TypeScript + Tailwind CSS 4** ساخته شده است:

```bash
bun install     # نصب وابستگی‌ها (فقط بار اول)
bun run dev     # اجرای سرور توسعه روی پورت 3000
```

لینک نهایی پس از انتشار (دیپلوی) روی هاست، قابل اشتراک‌گذاری با مهمانان است.

## 🎵 جایگزینی موسیقی با آهنگ دلخواه

موسیقی فعلی از این لینک پخش می‌شود:
`https://dll.biamusic.ir/Playlist/Lori-Shad/Lorishaad.mp3`

**برای گذاشتن آهنگ خودتان دو راه دارید:**

1. **فایل محلی (پیشنهادی):** فایل آهنگ را با نام `wedding-music.mp3` در پوشه
   `public/` پروژه قرار دهید، سپس در `src/config/wedding.ts` خط
   `'/wedding-music.mp3'` را به اولین جای فهرست `music.sources` منتقل کنید:

   ```ts
   music: {
     sources: [
       '/wedding-music.mp3',   // ← اولویت اول
       'https://dll.biamusic.ir/Playlist/Lori-Shad/Lorishaad.mp3',
     ],
   },
   ```

2. **لینک مستقیم:** به‌جای لینک فعلی، لینک آهنگ خودتان را در همان فهرست قرار دهید.

پخش‌کننده به‌ترتیب منابع را امتحان می‌کند؛ اگر اولی در دسترس نبود خودکار سراغ
بعدی می‌رود و در صورت خطا، پیام مناسب و دکمه «تلاش مجدد» نشان داده می‌شود.

> نکته: پخش موسیقی فقط با تعامل کاربر (کلیک روی «ورود به جشن») آغاز می‌شود؛
> این سیاست مرورگرهای موبایل است و دور زدنش ممکن نیست.

## ✨ امکانات

- کارت دعوت با قاب کرم، رزهای صورتی و سفید، تور و تزئینات طلایی
- دکمه «ورود به جشن» با درخشش طلایی و ترنزیشن سینمایی پرده
- تالار لوکس با لوستر، ریسه‌های رنگارنگ (روشن شدن یکی‌یکی)، قلب‌های شناور
- موسیقی شاد با دکمه روشن/خاموش همیشه در دسترس و اکولایزر متحرک
- مسیریابی با نشان، افزودن به تقویم، اشتراک‌گذاری لینک
- کاملاً موبایل‌فرست (Mobile First)، راست‌چین و فارسی
- دسترس‌پذیری: aria-label ها، کنتراست مناسب و پشتیبانی از reduced-motion
- عملکرد بهینه: انیمیشن‌های transform/opacity، Canvas سبک و توقف خودکار در پس‌زمینه
